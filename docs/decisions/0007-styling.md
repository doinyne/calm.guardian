# 0007: Styling with Uniwind, React Native Reusables and Reanimated

**Status:** Accepted · **Date:** 2026-11-02 · **Updated:** 2026-11-03 (mission control look, dark only)

## Context
Dean wants the polished, animated feel of KokonutUI, Motion and Bklit UI. All three are
**web-only** (React DOM + Tailwind), so they can't render in a React Native app. We need a native
equivalent with the same look and workflow, plus dark mode and accessibility for the stores.

## Options
1. **`StyleSheet` + typed tokens.** No dependencies, but every component is hand-built.
2. **Uniwind + React Native Reusables + Reanimated 4.**
   - **Uniwind:** Tailwind v4 class names compiled for React Native.
   - **React Native Reusables:** shadcn/ui ported to React Native, with copy-in components like KokonutUI.
   - **Reanimated 4:** native animations, with a CSS-style API close to Motion.
3. **NativeWind v4 instead of Uniwind.** More mature, but it uses Tailwind v3. Our website will use
   Tailwind v4, so the two would drift.
4. **Expo DOM components** running the web libraries in webviews. Slower, weaker accessibility, a
   non-native feel, and a risk under Apple guideline 4.2.

## Decision
**Option 2.**
- `apps/mobile/src/global.css` holds the Tailwind v4 theme: **one dark palette** (see below).
- Colour names follow shadcn's semantic tokens (`background`, `foreground`, `primary`, `muted`…).
- Values are the "mission control" palette, which replaced the v1 Stitch "Sanctuary" teal on 2026-11-03.
- **Canonical brand colours live in `packages/shared/src/theme-colors.ts`.** The app's CSS, the
  website's CSS (ADR-0010) and the splash screen are checked against it by tests, so they can't drift.
- Components are added with `npx @react-native-reusables/cli@latest add <name>` into
  `src/components/ui/`. **We own that code**: review it like our own, and adjust it for accessibility.
- Animations use Reanimated 4. They must respect the system "Reduce Motion" setting.

## Consequences
- Fast to build a consistent, good-looking UI, using the same Tailwind vocabulary as the website.
- Uniwind is younger than NativeWind. If it blocks us, switching to NativeWind keeps the components
  (React Native Reusables supports both) but means rewriting the theme file.
- `uniwind-types.d.ts` is generated by Metro and committed, so typecheck works in CI.
- Text must respect the system font size (no `allowFontScaling={false}`).
- Contrast is checked again in M7. `input` is chosen for 3:1 non-text contrast (WCAG 1.4.11).

## Update 2026-11-03: the mission control look
Dean chose a calm "mission control" direction: the app is the user's own command centre for taking
back control of their online life. Concept canvas: https://claude.ai/artifact/7xjWVbC1iG1HhxA6yQ3qUq
(private to Dean).
- **Dark only for launch** (`userInterfaceStyle: 'dark'`, Uniwind forced to `dark`). Light mode can
  come later if testers ask; the palette file is the one place to add it.
- **Colours with one job each:** deep navy background and panels; **aqua** (`primary`) means "you're
  in control" (buttons, active controls); **pink** (`hope`) is a rare ray of hope (good news, the
  core's spark, Restore). If pink is everywhere it stops meaning anything.
- **The core** (`CalmCore`) shows Calm Mode's state; small monospace **status labels** (`MonoLabel`)
  are always paired with a plain sentence.
- **Take the atmosphere, not the density** of sci-fi interfaces: one primary action per screen,
  readable text, slow optional motion, no flashing. **Never** body scans, heart-rate lines, "scanning"
  or surveillance cues: they suggest medical monitoring (no medical claims) and could make a
  vulnerable user feel watched.
- Brand fonts (Space Grotesk, JetBrains Mono) come next. They need a native build.
